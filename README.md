# 二连杆机械臂强化学习控制仿真平台

基于 NumPy 与 PyTorch 的二连杆平面机械臂到达（reach）任务仿真环境。目标是在统一任务定义与统一评测协议下，比较解析控制方法与无模型强化学习方法的表现边界，并逐项验证"经典控制在何种条件下失效、强化学习在哪些条件下具备替代价值"。

项目不依赖 ROS、GPU 与真实硬件，全部实验在 CPU 上可完整复现。

- 语言与依赖：Python 3.10+ / NumPy / PyTorch (CPU) / Matplotlib
- 代码规模：12 个脚本，约 3000 行
- 评测规模：50 组随机初始姿态与随机目标（seed=500）

---

## 1. 任务定义

平面二连杆机械臂（连杆长度 L1 = L2 = 0.3 m），末端需从随机初始姿态到达随机目标点。

| 项目 | 定义 |
|---|---|
| 状态空间 | 8 维：两关节角、末端位置、目标位置、末端到目标的相对位移 |
| 动作空间 | 2 维连续量，映射为关节角速度增量 |
| 成功判据 | 末端与目标距离 ≤ 0.05 m（TOL） |
| 单回合上限 | 200 步 |
| 奖励 | 距离负值（`dist`）或距离减少量（`progress`），见第 5.5 节 |

初始姿态与目标点每回合随机采样，固定 seed 保证各控制器在完全相同的 50 组样本上评测。

## 2. 主要结果

50 组随机样本，统一评测协议（详见第 7 节）：

| 控制器 | 成功率 | 平均步数 | 先验信息 |
|---|---|---|---|
| 零动作基线 | 0.0% | 200.0 | 无 |
| 随机策略基线 | 8.0% | 189.2 | 无 |
| PPO 冷启动，`dist` 奖励 | 10.0% | 181.0 | 仅观测与奖励 |
| PPO 冷启动，`progress` 奖励 | 86.0% | 52.0 | 仅观测与奖励 |
| 行为克隆（BC），专家演示 2.3 万条 | 76.0% | 99.0 | 专家动作 |
| BC + PPO 微调，`dist` 奖励 | 78.0% | 59.5 | 演示 + 交互 |
| BC + PPO 微调，`progress` 奖励，400 轮 | 90.0% | 42.1 | 演示 + 交互 |
| 雅可比伺服，gain = 1.5（默认） | 94.0% | 53.4 | 完整运动学模型 |
| 雅可比伺服，gain = 1.0（调优后） | 98.0% | 67.2 | 完整运动学模型 |

三点结论：

1. 在环境、超参数与随机种子完全一致的前提下，仅将奖励由 `-0.5d` 改为 `10·(d_prev − d)`，冷启动 PPO 成功率由 10.0% 提升至 86.0%。该结果推翻了本项目早期"冷启动失败源于任务难度"的判断，详见第 5.5 节。
2. 冷启动 PPO（86.0%）首次超过行为克隆（76.0%），且未使用任何专家演示。BC + PPO 微调在训练 400 轮后达到 90.0%，平均步数 42.1，优于伺服的 67.2 步。
3. 解析伺服仍为最高（98.0%），其优势来自已知运动学模型而非试错。在可写出闭式解的场合，解析方法的精度上限更高。

> 关于 BC 两组数字（76.0% / 99.0 步 与早期记录的 78.0% / 65.2 步）的差异：早期演示数据由 gain = 4.0（84.0%）的伺服生成，现版本由 gain = 1.0（98.0%）生成。演示质量主要影响平均步数（65.2 → 99.0），对成功率影响较小。

## 5. 实验

各实验均遵循同一套流程：提出可证伪的假设 → 设计单一变量的对照组 → 实测 → 记录结果与假设是否成立。

### 5.1 实验一：基准校准

**目的**：确定解析伺服的真实性能上限，避免以未调优的参数作为"专家基线"。

**问题来源**：执行延迟实验中，加入 3 步延迟后伺服成功率由 84.0% 升至 100.0%。延迟不应提升控制器性能，除非该控制器本身处于震荡状态。

**增益扫描结果**：

| gain | 成功率 | 平均步数 |
|---|---|---|
| 0.3 | 27.5% | 189.6 |
| 1.0 | 98.0% | 67.2 |
| 1.5 | 94.0% | 53.4 |
| 2.0 | 94.0% | 44.0 |
| 4.0 | 84.0% | 49.1 |
| 8.0 | 82.5% | 47.4 |

gain = 4.0 时控制器存在明显过冲，在目标附近往复震荡；延迟项起到低通滤波作用，恰好压制了震荡，因此出现"加延迟反而更好"的假象。

**影响**：本项目早期以 gain = 4.0 的 84.0% 作为专家上限，据此得出"BC 仅差 6 个百分点"的结论。真实差距为 22 个百分点（98.0% vs 76.0%），两者对应的工程判断完全不同。本仓库所有标注"专家"的数据均以 gain = 1.0（98.0%）为准，gain = 1.5（94.0%）作为默认值，因其在成功率与步数之间更均衡。

**二维扫描**：同时扫描增益与延迟后，得到更优组合 `gain = 3.0 + delay = 3`，成功率 100.0%、平均 34.6 步。高增益单独使用会震荡（92.5% → 87.5% → 82.5%），配合延迟后回到 100.0%，且步数约为 gain = 1.0 的一半。延迟在此处表现为预测补偿：控制器依据 3 步之前的状态计算，等价于一个粗糙的前向补偿器。

### 5.2 实验二：关节限位（假设被否定）

**假设**：对 θ₂ 施加 20°–160° 限位后，伺服会被约束边界阻挡，专家性能下降，RL 获得优势。

**结果**：

| 配置 | 无限位 | 有限位 |
|---|---|---|
| 伺服 | 84.0% / 49.1 步 | 100.0% / 24.9 步 |
| BC | 78.0% / 65.2 步 | 80.0% / 60.2 步 |
| BC + PPO 微调 | 78.0% / 59.5 步 | 94.0% / 30.2 步 |

（本组数据使用 gain = 4.0 采集。以 gain = 1.5 复测时，无限位为 94.0%，有限位不低于该值，"限位不导致专家失效"的结论不变。）

**结论**：假设被否定。伺服成功率由 84.0% 升至 100.0%，步数减半。原因是 `det J = L1·L2·sin θ2`，θ₂ = 0° 与 180° 恰为奇异位形，限位将这两个位形排除在外，雅可比不再退化，任务难度实际降低。

**衍生发现**：将两个任务纳入同一套微调流程对比，微调增益差异明显。

| 任务 | 微调增益 |
|---|---|
| 无限位（含奇异区） | 78.0% → 78.0%（+0.0），步数缩短 8.7% |
| 有限位（无奇异区） | 80.0% → 94.0%（+14.0），步数 60.2 → 30.2 |

同环境、同超参数、同起点，唯一差异是训练样本中是否包含病态奇异区。这表明冷启动失败的另一个来源是奇异区：该区域末端位移极小但关节速度极大，梯度信号剧烈且不稳定，策略难以收敛。此类区域对梯度下降本身不友好，并非探索不足所致。

据此可将"RL 的适用边界"收紧为：RL 适用于**动力学良态但缺乏解析模型**的问题；在动力学本身病态的区域（奇异、接触、碰撞），RL 与传统方法同样困难。

### 5.3 实验三：关节摩擦死区与 Sim2Real

**假设**：关节静摩擦死区无法被前两个实验中的副作用补偿，应导致解析控制器结构性失效。

**死区模型**：

```
|命令| < d      → 关节不产生位移（推力未超过静摩擦）
|命令| ≥ d      → 实际速度 = sign(a)·(|a|−d)/(1−d)，满幅指令仍对应满速
```

与震荡、超调不同，死区属于结构性不可驱动：雅可比伺服在误差较小时输出的小幅指令会整体落入死区，末端将停在距目标数厘米处无法继续逼近。增大增益只能使指令越过阈值，但误差趋零时指令仍趋零，精度与推力在死区约束下互斥。

**实验设置**：按标准 Sim2Real 流程搭建——在理想模型（无死区）中采集演示训练 BC，再部署至含死区的目标环境（d = 0.25）。

| 控制器（目标环境，50 回合） | 成功率 | 平均步数 | 最终残距 |
|---|---|---|---|
| 伺服（源环境成绩） | 98.0% | 67.2 | 8.5 cm |
| 伺服（目标环境，gain 在 0.5–128 间扫描，最优 g = 32） | 80.0% | 50.7 | 21.2 cm |
| 伺服 + dither（σ = 0.3 抖动） | 95.3% | 36.8 | 6.7 cm |
| BC（源环境训练，直接部署） | 0.0% | 200.0 | 66.1 cm |
| BC + dither | 79.3% | 127.8 | 7.4 cm |
| BC + 目标环境 PPO 微调，确定性部署 | 0.0% | 200.0 | 42.7 cm |
| BC + 目标环境 PPO 微调，采样部署 | 91.3% | 84.0 | 5.4 cm |

四项结论：

**（1）死区确实导致解析控制器结构性失效。** 伺服由 98.0% 降至 80.0%，且该成绩是扫描 9 个增益值后的最优结果。BC 的退化更严重：源环境 76.0%，目标环境 0.0%，Sim2Real 差距达 76 个百分点。诊断结果与假设一致：BC 的平均指令幅度为 0.250，死区阈值为 0.25，约每两步即有一整步完全无法驱动关节。

**（2）有效解是抖动，而非提高精度。** 对伺服施加 σ = 0.3 的随机抖动后，成功率由 80.0% 升至 95.3%，步数减半。该方法是控制工程中突破静摩擦的常规手段，本质是通过噪声将小幅指令抬升越过阈值。

**（3）RL 自行发现了抖动策略，但未超过人工设计的 dither。** 91.3% 对 95.3%，低 4 个百分点，步数为人工方案的 2.3 倍（84.0 对 36.8）。结论应表述为：在已知需要抖动且已知抖动幅度的前提下，人工设计更高效；RL 的价值在于无需人工预先给定该先验，仅凭奖励信号即从 0.0% 达到 91.3%。

**（4）部署协议对结果的影响超过算法本身。**

| 部署方式 | 成功率 |
|---|---|
| 取均值（确定性，工程常规做法） | 0.0% |
| 按策略分布采样 | 91.3% |

同一份权重，两种部署方式相差 91.3 个百分点。原因在于确定性部署的平均指令幅度为 0.237，低于死区阈值 0.25；采样部署为 0.384，随机分量使指令间歇性越过阈值。

该项目早期版本仅报告贪心评测结果，得到 0.0%，据此曾得出"RL 在本任务失败"的错误结论；而训练日志中的采样成功率为 85%–100%。两个数据均真实，报告哪一个决定了结论的正负。

因此，任何 RL 成功率数据都必须同时注明部署方式。

### 5.4 实验四：奖励函数改造

**前提**：此前所有关于冷启动失败的分析均建立在"奖励函数由任务给定"这一假设上，但实际奖励是本项目自定义的。

**原奖励（`dist` 模式）**：`r = -0.5·d - 0.01`，含义为"当前离目标多远"。

连续 6 步实测值：

```
dist     -0.9021  -0.9134  -0.9219  -0.9278  -0.9310  -0.9315
progress -0.2881  -0.2346  -0.1808  -0.1270  -0.0738  -0.0217
```

`dist` 在 6 步内仅变化 0.03，其刻画的是状态好坏，而非动作质量。advantage 定义为"当前动作相对平均水平的增益"，当所有动作的奖励值接近时，advantage 退化为噪声，PPO 仅能获得稀疏的终止信号，此前所有步骤均产生无效梯度。

**新奖励（`progress` 模式）**：`r = 10·(d_prev − d) - 0.01`，含义为"本步动作的改善量"。

该形式等价于 potential-based shaping（Φ(s) = −d(s)，F = γΦ(s′) − Φ(s)）。Ng 等（1999）证明此类塑形不改变最优策略，仅将学习信号分摊到每一步。因此这构成一个严格的对照实验：环境、动力学与最优解均不变，唯一变量是信号密度。

**结果**：

| 配置 | 成功率 | 平均步数 |
|---|---|---|
| PPO 冷启动，`dist` 奖励 | 10.0% | 181.0 |
| PPO 冷启动，`progress` 奖励 | 86.0% | 52.0 |
| BC 基线（2.3 万条专家演示） | 76.0% | 99.0 |
| BC + `dist` 微调（旧流水线） | 78.0% | 59.5 |
| BC + `progress` 微调，150 轮 | 50.0% | 121.8 |
| 伺服（上限） | 98.0% | 67.2 |

**（1）冷启动失败的主因是奖励函数，而非任务性质。** 早期分析将病因归为"需从零重建 J⁺，任务性质不匹配"，而同一段落中"说不出这一步走对没有"的表述已准确指出了问题所在。修改奖励后，在同样从零开始、同样不使用演示的条件下，成功率升至 86.0%。

**（2）无模型 RL 首次超过行为克隆。** 86.0% 对 76.0%，且未使用任何专家轨迹。这说明"先克隆再微调"的流水线在本任务上并非必要；该流水线本身是真实机器人部署的标准做法，问题在于将其视为必需步骤。

**（3）异常结果及其验证。** BC + `progress` 微调 150 轮仅 50.0%，低于 BC 基线 26 个百分点。假设为：BC 学到的是伺服的平滑控制风格，而 `progress` 奖励的最优解是每步最大化距离缩减的激进风格；PPO 的 `clip = 0.2` 限制单步更新幅度，150 轮不足以完成风格切换，策略停留在两种风格之间。

为验证该假设，设置两个放宽约束的对照组：

| 配置 | 成功率 | 平均步数 | 平均指令幅度 |
|---|---|---|---|
| BC 起点（平滑风格） | 76.0% | 99.0 | 0.134 |
| `clip = 0.2`，150 轮 | 50.0% | 121.8 | — |
| `clip = 0.4`，150 轮 | 56.0% | 107.0 | 0.199 |
| `clip = 0.2`，400 轮 | 90.0% | 42.1 | 0.375 |

假设成立。平均指令幅度 0.134 → 0.199 → 0.375 单调上升，表明策略确实在由平滑风格向激进风格迁移；成功率呈 76.0% → 56.0% → 90.0% 的 U 型分布。

**中间状态劣于两端。微调过程必须先经历性能下降才能回升。** 150 轮时策略处于 U 型谷底，性能低于微调起点；训练至 400 轮走完全程后达到 90.0%，高于冷启动的 86.0%，也高于其余所有 RL 配置，且平均步数为全项目最短（42.1 步，伺服为 67.2 步）。

工程含义：微调中途停止存在风险。不能因"微调后性能下降"判定方法无效，该现象可能只是处于风格迁移的谷底。判断是否继续训练应观察风格迁移的可观测指标（如平均指令幅度），而非仅看成功率当前值。对照组 `clip = 0.4`、150 轮仅 56.0%，说明放宽单步更新幅度无法替代训练轮数，瓶颈在于切换所需的轮数。

### 5.5 实验五：观测噪声

**假设**：伺服控制律 `q̇ = J⁺·(p_target − p_now)` 假定误差测量准确。真实编码器与视觉反馈均含噪声，J⁺ 会将噪声按增益放大，因此噪声应导致伺服失效。

**设置**：对观测的 dx/dy 分量叠加高斯噪声，σ 从 0 扫描至 0.2 m（TOL = 0.05 m，故 σ = 0.1 表示测量误差为到达阈值的两倍）。每个 σ 下伺服均扫描增益取最优；另设传统工程解——对误差做滑动平均低通滤波（窗口 3 / 5，同样扫描参数）。RL 侧采用冷启动 + `progress` 奖励，训练与评测的噪声分布与强度一致（σ = 0.1）。

| 方案 | 成功率 | 平均步数 |
|---|---|---|
| 伺服，σ = 0.00 | 98.0% | 67.2 |
| 伺服，σ = 0.02 | 98.0% | 129.1 |
| 伺服，σ = 0.05 | 98.0% | 129.5 |
| 伺服，σ = 0.10 | 98.0% | 130.6 |
| 伺服，σ = 0.20 | 98.0% | 68.7 |
| 伺服 + 低通滤波（窗口 3，任意 σ） | 100.0% | — |
| PPO 冷启动，σ = 0.10，贪心部署 | 32.0% | 155.7 |
| PPO 冷启动，σ = 0.10，采样部署 | 38.0% | 147.6 |

**伺服成功率不降反稳，加低通滤波后达到 100.0%，RL 仅 32.0%。假设被否定。**

三项机制解释该结果：

1. **"进入容差即终止"的判据对噪声免疫。** 成功不要求稳定保持，只需某一时刻末端落入 5 cm 半径内。抖动不降低命中概率，反而增加穿越边界的概率。低通滤波的价值因此不体现在成功率（裸伺服已达 98.0%），而体现在稳定性与最终残距，本实验未测量这两项指标。
2. **伺服具备增益调节能力，最优值随噪声左移。** 无噪声时最优 gain = 1.0；σ ≥ 0.02 后最优值变为 0.5（低增益不放大噪声，代价是步数由 67.2 增至 129.1）。伺服以单一参数即可应对。
3. **RL 的劣势来自结构而非训练不足。** 同分布噪声、400 轮训练、`progress` 奖励（无噪声条件下可达 86.0%）下仍仅 32.0%。原因在于**无状态策略无法利用历史信息**：低通滤波的本质是时间维度上的信息累积（滤波器内部维护历史队列），而 MLP 策略每帧独立决策，无法跨帧平均。RL 并非未见过噪声，而是架构上不具备观察历史的能力。

### 5.6 实验六：动力学升级与采样率下限

前五个实验全部运行在速度模式下：动作直接是关节角速度，`θ ← θ + ω·dt` 只是一句加法。该模式隐含"伺服内环完美跟踪"的强假设，质量、惯量、重力与科里奥利力均不存在。本节补上刚体动力学，将动作空间改为关节力矩，使问题从运动学跟踪变为真正的控制问题。

**动力学模型**：`M(q)·q̈ + C(q,q̇)·q̇ + G(q) = τ`，参数取 L1 = 1.0 m、L2 = 0.8 m、m1 = 3.0 kg、m2 = 2.0 kg，均质细杆转动惯量。力矩上限 60 N·m（该臂架重力矩峰值 42.9 N·m，留三成余量）。

**五项物理一致性自检**（`dynamics.py`）：

| 检查项 | 残差 |
|---|---|
| 惯性矩阵对称且正定 | 0.000e+00 |
| 逆动力学 → 正动力学往返 | 8.882e-15 |
| 重力补偿静态平衡 | 1.274e-15 |
| 无外力自由摆动 10 s 能量守恒 | 8.112e-10（相对） |
| 由动能反推惯性矩阵 | 2.220e-16 |

**结果一：动作空间对比**（双方单回合均为 10 s）

| 控制器 | 模式 | 成功率 | 平均到达时间 |
|---|---|---|---|
| 雅可比伺服，gain = 1.0 | 速度 20 Hz | 98.0% | 3.36 s |
| PD，不补重力 | 力矩 100 Hz | 36.0% | 6.69 s |
| PD + 重力补偿 | 力矩 100 Hz | **100.0%** | **0.81 s** |
| 计算力矩（反馈线性化，全模型） | 力矩 100 Hz | 98.0% | 1.15 s |

**结果二：模型知识的分级价值**（同一组增益 Kp = 100、Kd = 20）

| 掌握的信息 | 成功率 | 平均到达时间 | 末态距离 |
|---|---|---|---|
| 无（裸 PD） | 36.0% | 6.69 s | 147.7 mm |
| 重力 | 100.0% | 0.81 s | 46.3 mm |
| 重力 + 惯量 + 科里奥利力 | 98.0% | 1.15 s | 112.8 mm |

补上重力一项即从 36.0% 提升到 100.0%，说明**在本任务中重力是模型失配的主导项**，惯量与科里奥利力影响较小。全模型控制器（98.0%）未超过 PD + 重力补偿，原因是反馈线性化将闭环固有频率固定为 √Kp = 10 rad/s，而裸 PD 的等效刚度在低惯量方向上更大（24 rad/s），响应更快；两者的差异属于调参而非结构。

**结果三：重力下垂量与理论值吻合**（静态悬停，Kd = 20）

| Kp | 不补重力·末端偏移 | 补重力·末端偏移 | 理论值 G/Kp |
|---|---|---|---|
| 30 | 1699.9 mm | 0.0 mm | 1360.4 mrad |
| 100 | 736.9 mm | 0.0 mm | 408.1 mrad |
| 300 | 254.0 mm | 0.0 mm | 136.0 mrad |
| 1000 | 75.6 mm | 0.0 mm | 40.8 mrad |

不补重力时下垂量与 Kp 成严格反比（Kp 每增 3.3 倍，偏移降至约 1/3.3），与 `Kp·e = G` 的解析解一致；补重力后稳态误差精确为零。

**结果四：采样率下限（本项目最意外的发现）**

数字控制器两次采样之间力矩恒定，重力补偿项 G(q) 也冻结在采样时刻的值。这段时间内手臂相当于倒立摆，重力梯度会放大姿态误差，须待下一拍纠正。以重力矩最大的姿态（θ1 = 0，手臂水平外伸）线性化，按零阶保持精确计算闭环谱半径：

| 控制频率 | 成功率 | 平均到达时间 | ZOH 谱半径 |
|---|---|---|---|
| 20 Hz | 78.0% | 3.08 s | 5.45（发散） |
| 50 Hz | 100.0% | 0.86 s | 1.39（发散） |
| 100 Hz | 100.0% | 0.81 s | 0.98（稳定） |
| 200 Hz | 100.0% | 0.81 s | 0.99（稳定） |
| 500 Hz | 100.0% | 0.81 s | 1.00（稳定） |

两点需要注意：

1. **20 Hz 的 78.0% 不代表控制有效。** 控制环发散后手臂在关节限幅与力矩饱和的约束下乱撞，仍会偶然穿过目标球。判据不能只看成功率：到达时间从 0.81 s 退化到 3.08 s（近 4 倍）才是真实代价。
2. **50 Hz 行同样发散（谱半径 1.39），成功率却为 100.0%。** 谱半径是在最不利姿态下计算的，采样到的具体轨迹未必经过该姿态。这说明**单用任务成功率评估控制器不足以发现不稳定**，必须同时报告稳定裕度。

本项目的全部力矩实验因此固定在 100 Hz（dt = 0.01 s），与真实机器人控制器 1 kHz 的量级差一个数量级，但已跨过稳定性边界。速度模式实验维持 dt = 0.05 s 不变，以便与前五个实验的数字直接比较。

代码：`dynamics.py`（刚体动力学与自检）、`env.py` 的 `control_mode="torque"` 分支、`task_dynamics.py`（本节全部实验与 `dynamics_result.png`）。

### 5.7 实验七：力矩空间的强化学习（未跑通，附诊断）

5.6 节全部使用模型型控制器。本节把 RL 放进力矩空间，问一个更实际的问题：**当控制器手里的参数表是错的，RL 能不能只靠反馈补回来？**

**设置**：真实机构质量是控制器以为的两倍（连杆质量与转动惯量同步翻倍），控制器仍按标称参数计算重力补偿。这是工程中最常见的失配形式，比"完全不建模"更真实。力矩上限放宽至 90 N·m——重一倍的机构应配更大功率的驱动器，否则重力矩峰值 85.8 N·m 直接顶到 60 N·m 上限，那是推不动而非控不住。观测 10 维（8 维基础观测加 2 维关节速度），动作 2 维归一化力矩，100 Hz。

| 控制器 | 成功率 | 平均到达时间 |
|---|---|---|
| PD + 标称重力补偿（工程师实际能做到的） | **58.0%** | 4.85 s |
| PD + 真实重力补偿（作弊上界） | **98.0%** | 1.13 s |
| 行为克隆 BC，40000 步，MSE 2.7e-4 | 44.0% | 8.6 s |
| BC + PPO，150 轮 | 18.0% | 9.0 s |
| BC + PPO，120 轮（`prog_scale` 按 dt 缩放、回合缩短至 3 s） | 16.0% | 2.8 s |

**结论：力矩空间的 RL 没有跑通。** BC 与 PPO 均低于标称专家，微调相对 BC 不升反降。

**这个负结果不能解释成"失配导致 RL 失效"。** 诊断实验把真实机构换回标称机构（此时专家 100.0%），保持其余配置完全不变，同一套管线仍只达到 44.0%。瓶颈在力矩空间的策略学习本身，与模型误差无关。

三条原因，均已用对照实验区分：

1. **时间尺度变了，但不是主因。** 速度模式一回合 200 步，力矩模式 100 Hz 下一回合 1000 步，信用分配跨度大 5 倍；`prog_scale=10` 是按 20 Hz 调的，100 Hz 下每步位移小 5 倍，奖励信号被固定的 −0.01 惩罚项淹没。按比例改为 50 重训后无改善，此项排除。
2. **复现误差累积（compounding error）。** BC 单步 MSE 从 5.8e-3 降到 2.7e-4，改善两个数量级，闭环成功率却只在 22%–44% 之间波动，不随拟合变好而上升。单步都准，整条轨迹仍然飘。
3. **演示质量受限于专家。** 示范者本身只有 58.0% 成功率，其演示中混有大量"补救动作"，与正常控制动作混合学习会把策略拉偏。

**方法学结论**：本项目在速度空间里 RL 可用（86.0% / 90.0% / 91.3%），在力矩空间里尚未打通。这与"RL 行或不行"无关——它是同一套算法在两个动作空间上的可学性差异，而这个差异必须实测才知道。补齐这一环需要更好的探索算法（SAC / TD3）、并行环境与更长的训练预算，不是再调几个超参。

代码：`task_torque_rl.py`。

### 5.8 实现缺陷记录

冷启动 PPO 在前两版中均为 2.0%，期间定位并修复五个缺陷。前三个修复后仍不收敛，后两个修复后达到 78.0%。五个缺陷的共同特征是**程序不报错、训练曲线平滑**，仅在结果层面体现为性能停滞，与语法错误相比定位难度显著更高。

| 编号 | 缺陷 | 表现与修复 |
|---|---|---|
| 1 | `log_std` 无上界 | 被梯度持续推大，采样值大量落在 [-1, 1] 外并被裁剪为 ±1，策略退化为 bang-bang 行为，熵转为负值 |
| 2 | `log_prob` 使用裁剪前的动作 | 环境执行裁剪后动作，importance ratio 与实际动作不一致 |
| 3 | 收敛阈值 0.02 m 过严 | 随机策略几乎无法命中，buffer 中成功样本接近 0，终止奖励从未被利用。放宽至 0.05 m 后仍为 2.0%，确认非主因 |
| 4 | `clamp` 锁死 `log_std` | 使用 `log_std.clamp(log(0.1), log(0.6))` 限制标准差，而 clamp 在边界外梯度恒为 0。BC 的负对数似然偏好小方差，将 `log_std` 推至下界以下，PPO 微调时梯度无法回传，熵恒定为 -1.767。策略永久退化为确定性，无探索，微调将 BC 的 80.0% 拖低至 66.0%。改为软映射 `0.1 + 0.5·sigmoid(log_std)` 后熵恢复流动（0.74–0.85） |
| 5 | critic 由随机初始化直接进入 PPO | BC 阶段仅以负对数似然训练 actor，value 网络仍为随机权重。前几十轮 critic 估计严重偏离，advantage 为噪声，梯度破坏已训练好的策略。补充策略评估（以 BC 策略采样、将 critic 回归到真实折扣回报）后，微调不再破坏起点 |

### 5.9 环境实现要点

**正运动学**：`T = R(θ1)·Trans(L1,0)·R(θ2)·Trans(L2,0)`。自检中将矩阵连乘结果与三角公式对照，误差为 0.000e+00。关节数增加时仅需继续右乘，无需重新推导。

**逆运动学**：

```
cos θ2 = (r² − L1² − L2²) / (2·L1·L2)
sin θ2 = ±√(1 − cos²θ2)
```

正负号对应肘上 / 肘下两组解。`r > L1+L2` 或 `r < |L1−L2|` 时无解，不可达是数学结论而非程序分支。

**奇异点**：`det J = L1·L2·sin θ2`，为零即位形奇异。奇异点不等于不可达，而是"存在无法运动的方向，或需无穷大关节速度才能运动"。末端沿径向外移 1 m/s 时所需关节速度：

| θ2 | 纯伪逆 | DLS（λ = 0.05） |
|---|---|---|
| 0.5° | 282.15 rad/s | 1.41 rad/s |
| 2° | 70.54 rad/s | 5.25 rad/s |
| 10° | 14.12 rad/s | 9.42 rad/s |
| 90° | 1.72 rad/s | 1.71 rad/s |
| 179.5° | 118.02 rad/s | 3.29 rad/s |

这是工业控制器必须引入阻尼的原因：属于电机安全工作边界，而非优化选项。阻尼并非无代价，奇异附近的速度被主动压低，意味着放弃该区间的精确跟随，以精度换取稳定。

**终止与截断分离**：`terminated`（到达目标）后未来价值确为零；`truncated`（超时）只是回合被中断，状态仍有继续改善的余地。将两者合并处理等价于告知 agent"到达与超时同样糟糕"，训练必然发散。

**PPO 连续动作**：高斯策略，`tanh` 将均值压缩至 [-1, 1]，GAE 计算优势，`clip(ratio, 1±0.2)` 限制单步更新幅度。裁剪的作用不是加速收敛，而是防止单步更新推翻已学到的策略。

## 7. 局限与边界

- **可写出闭式解的场合，解析控制仍领先**（98.0% 对 90.0%），且该差距源于方法结构而非参数调优。RL 的价值在于模型未知或失配时仍可部署，以及以更少动作达到接近的效果（42.1 步对 67.2 步）。
- **90.0% 对训练轮数高度敏感**：同一配置 150 轮为 50.0%，400 轮为 90.0%，过程呈 U 型。不能以单点性能判定微调方法有效性。
- **模型失配场景（摩擦死区）下 RL 恢复至 91.3%，但未超过人工 dither 的 95.3%**，且步数为后者的 2.3 倍。
- **"使专家失效"的四个候选场景中，三个结果为反向**（限位、延迟、观测噪声均未削弱伺服），仅摩擦死区成立。结论需逐一实证，不可先验推断。
- **观测噪声下 RL 仅 32.0%，伺服 98.0%**。该结果源于无状态策略无法利用历史信息的结构性限制，不可外推至帧堆叠或 RNN 方案（未实验）。
- **本项目为纯仿真，未进行真实硬件验证。** 环境支持速度模式与力矩模式，但力矩模式运行在 100 Hz，仅够跨过稳定性边界；真实机器人控制器通常为 1 kHz，本项目的采样率低一个数量级。
- **RL 在力矩空间尚未跑通。** BC 与 PPO 均低于模型型控制器（44.0% / 18.0% 对 58.0%），且对照实验表明这与模型失配无关——同一套管线在完全匹配的环境里也只有 44.0%。因此本项目的 RL 结论仅适用于速度动作空间。
- **动力学参数为估计值，未经实物辨识。** 连杆质量与转动惯量取自均质细杆假设，真实机构的减速器惯量、齿隙与柔性未建模。摩擦仅以静摩擦死区近似，未包含 Stribeck 曲线与黏性阻尼。
- **本项目对嵌入式 MCU 岗位为加分项，对机器人算法与具身智能方向为主项**。MCU 岗位的核心要求（FreeRTOS、DMA、CAN、实物闭环控制）需硬件平台支撑，与本项目不重叠。

## 9. 已知设计失误

观测噪声实验原计划以"单回合内进入容差的次数"量化目标附近的抖动程度，预期无噪声时为 1 次、抖动时反复穿越边界。但环境在进入容差时立即终止，该统计量恒等于成功率，不提供额外信息。`noise_result.png` 中相应曲线因此冗余，伺服 0.98 与 PPO 0.32 两条线即为各自成功率。准确测量抖动需将成功判据改为"进入容差后稳定 N 步"。
